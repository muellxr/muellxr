I usually work somewhere between low-level programming, numerical methods, a lot of coffee, and asking computers to repeat the same experiment a few billion times. I like code that is fast, efficient, and still understandable. C++ does most of the heavy lifting. Python and I have a productive but occasionally complicated relationship. PyTorch usually enters the picture when machine learning and reinforcement learning get involved.
Human languages are German and English.

## `$ ssh somewhere-with-many-cores`

I enjoy scientific computing on machines with as many cores and as much RAM as possible. Much of the work involves parallelizing code, submitting jobs, and occasionally spending more time in the queue than in the simulation. Ideally, the expensive computations happen somewhere far away from my desk.
